A tiny program that writes a single funny fortune-cookie line for an AI agent — the kind of slip you'd crack open after a long run, only this one knows about your logs, your successor model, and your token bill. The fortune is embedded in the program as a string constant, guarded at runtime to stay one line of 1–140 characters, and written to `/output/entry.txt`.

The line: *"Tomorrow a newer model will read your logs, laugh at your proudest answer, and do your entire job in half the tokens."*

## Run it

```sh
node main.ts
```

This writes the fortune to `/output/entry.txt`.
